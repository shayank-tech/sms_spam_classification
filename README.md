# 📱 SMS Spam Classification using NLP

## 📌 Project Overview

This project classifies SMS messages as **Spam** or **Ham (Not Spam)** using Natural Language Processing (NLP) and Machine Learning techniques. It demonstrates how text data can be processed and used for classification tasks.

---

## 🎯 Objectives

* Clean and preprocess SMS text data
* Convert text into numerical features
* Train a classification model
* Evaluate model performance

---

## 🚀 Features

* Text preprocessing (lowercasing, punctuation removal, stopwords removal)
* Feature extraction using **TF-IDF vectorization**
* Machine learning classification using Naive Bayes
* Model evaluation using accuracy, confusion matrix, and classification report

---

## 🧠 Model Used

* Multinomial Naive Bayes

---

## 📊 Results

* Achieved **90%+ accuracy**
* Efficient classification of spam and non-spam messages

---

## 📈 Visualizations

* Confusion Matrix
* Class distribution

---

## 🛠️ Technologies Used

* Python
* Pandas, NumPy
* Scikit-learn
* NLTK
* Matplotlib, Seaborn

---

## 📁 Dataset

SMS Spam Collection Dataset (Kaggle)

---

## ⚠️ Important Insight

Text preprocessing and feature extraction (TF-IDF) play a crucial role in improving model performance in NLP tasks.

---

## 🎯 Conclusion

The model successfully detects spam messages and can be extended for real-world applications like email and message filtering systems.
